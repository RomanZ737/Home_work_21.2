# Home_work_21.2
General Bootsram and HTML work
В проекте свёрстаны 4 страницы:
* Главная (main.html)
* Каталог (catalog.html)
* Категория 1 (category_1.html)
* Контакты (contacts.html)

В файле main.py реализован простой сервер на базе пакета http.server.
При запуске файла, сервер работает по адресу http://localhost:8080, при отправке запроса GET возвращает сраницу
станицу contacts.html.
При отправке запроса POST сервер возвращает в консоль содержание запроса.
